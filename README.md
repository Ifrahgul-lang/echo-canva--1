# Echo Canvas - Complete Sound Visualization Experience

Echo Canvas is an innovative web application that transforms sounds into beautiful, accessible art through AI. This professional-grade application features multiple control methods including voice commands, gesture controls, and traditional interactions.

## 🚀 Features

### Core Functionality
- **Sound-to-Art Transformation**: Record sounds and transform them into visual artwork
- **Multiple Visual Styles**: Choose between Default Style (full color spectrum) and Accessible Style (high contrast)
- **Real-time Voice Commands**: Screen-specific voice recognition system
- **Gesture Controls**: Tap, hover, and click interactions
- **Accessibility First**: Designed with WCAG compliance in mind

### Voice Command System
- **Screen-Specific Commands**: Voice commands only work on the current screen
- **No Command Conflicts**: Proper priority system prevents conflicts
- **Automatic Activation**: Voice recognition starts automatically
- **Confirmation System**: Voice command buttons with confirmation prompts

### Control Methods
- **Voice**: Say commands like "default style", "start recording", "update art"
- **Touch**: Tap once, twice, or three times for quick actions
- **Mouse**: Hover for automatic selection (2 seconds)
- **Keyboard**: Full keyboard navigation support

## 🎯 Voice Commands by Screen

### Selection Screen
- `"default style"` or `"accessible style"`
- `"help"` for assistance

### Creation Screen
- `"start recording"` or `"stop recording"`
- `"back"` to return to selection
- `"help"` for assistance

### Reveal Screen
- `"update art"` or `"one"`
- `"share link"` or `"two"`
- `"describe again"` or `"three"`
- `"create new"` for more options
- `"help"` for assistance

### Modals
- **Create New Modal**: `"try new artwork"`, `"add instruction"`, `"start fresh"`
- **Update Modal**: `"try again"`, `"add instruction"`, `"cancel"`

## 🎤 Voice Command Buttons

Hold click on these buttons and say "yes" to confirm:
- **Try Again**: Regenerate artwork with same sound
- **Add Instruction**: Add text or voice instruction
- **Start Fresh**: Restart the entire flow
